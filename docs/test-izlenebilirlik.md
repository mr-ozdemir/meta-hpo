# Test izlenebilirliği

Bu belge meta-hpo test paketinin hangi test yazma kuralını hangi testlerle karşıladığını ve bu testlerin kütüphanenin hangi gereksinimini doğruladığını gösterir. Testler kural bazlı iş kalemleri halinde yazılıp gözden geçirildi, ardından `tests/` altında birim adlı dosyalarda birleştirildi. Ayrıntılı test planı (özellikler, katmanlar, strateji, seçim haritası, kör noktalar) `tests/conftest.py` modül docstring'indedir.

## Özet

- Test dosyası: 58 (`test_<birim>.py` veya `test_<birim>_<yön>.py`, ayrıca 9 kesişen dosya).
- Toplanan test: 3879, hepsi geçiyor; tüm paket yaklaşık 20 saniyede koşuyor.
- Her dosya tek başına ve ters sırada (`METAHPO_TEST_REVERSE=1`) da geçiyor.
- Satır kapsamı %99 (410 satırdan 406'sı), dal kapsamı 106/106. Kapsanmayan dört satır `Parameter` taban sınıfının `NotImplementedError` gövdeleridir (space.py 48, 52, 56, 59).
- `ruff check`, `ruff format --check` ve `mypy` temiz; testlerde `#` yorum satırı yok.
- Bağımlılık: yalnız pytest, numpy ve standart kütüphane.

## Çalıştırma

```console
PYTHONPATH=src python -m pytest -q
METAHPO_TEST_REVERSE=1 PYTHONPATH=src python -m pytest -q
PYTHONPATH=src python -m coverage run --branch --source=src/metahpo -m pytest -q
python -m coverage report -m
```

## İzlenebilirlik matrisi

Matris iş kalemlerine göre gruplanmıştır. Her başlığın altındaki cümle kalemin doğruladığı kütüphane gereksinimidir; tabloda her kural kimliği, onu karşılayan testlere (dosya ve test adı) bağlanır. Parametreli testler bir kez sayılır. `test_abc.py` ve `test_space.py` içindeki özgün testler `test_traceability.py` içindeki `REQUIREMENTS` matrisinde gereksinim kimliklerine (R-...) bağlıdır.

## Birleştirme notları

- 27 iş kaleminin tümü birleştirildi. Son gözden geçirmesi 'revise' olan dört kalemin (suite-skeleton, boundaries, fault-history-regressions, fuzz-abnormal-inputs) testleri geçiyor ve stil listesine uyuyor; son gözden geçirmede istenen düzeltmeler uygulandı: `import metahpo as mh` ve yıldızlı import modül eşlemesine eklendi, `neighbour_value` 0 eşiği en küçük alt normal değerlerle sınanıyor, scout testine tek limit (3) durumu eklendi, bir docstring cümlesi düzeltildi.
- Aynı ada sahip testler benzersiz adlar aldı; birebir aynı gövdeli bir test (`Space({})` hatası) çıkarıldı, iki parametre tablosu tek testte birleşti. Aşırı uzun beş test adı kısaltıldı.
- Meta testler birleşik pakete uyarlandı: `tests/conftest.py` planı tüm dosyaları, katmanlarını ve seçim haritasını listeliyor; `conftest` importu paketin kendi parçası olarak izinli; gövde denetimi stil listesindeki if/for/while kuralına hizalandı (comprehension serbest); `test_traceability.py` yetim test denetimi `TRACED_MODULES` modülleriyle sınırlı, diğer modüller bu belgede kural kimliğiyle izleniyor.
- Her modül docstring'i plan kuralı gereği 'Input space:' ve 'Subset:' satırlarını taşıyor.
